# The Tuftlings, rebuilt from scratch (Hayden, 28 Nov 2026)

Hayden didn't like the first Tuftlings, which were made with the same Blender script as every other character
("you seem to think you have to use the same script ... start over from scratch"). These are made the way Hayden
chose for all characters: a straight-on picture in the style of Hayden's own picture, then TRELLIS.2.

`hayden_archer.jpg.b64` is Hayden's picture (base64, so it could be sent from the cloud without LFS). Decode it to
`hayden_archer.jpg` and use it as the style reference.

The eight (names are still drafts): Fennick (brave lookout, boy), Thistle (flowers, girl), Moss (sleepy, boy),
Bluebell (shy note writer, girl), Bracken (grumpy but kind, boy), Clem (digger, girl), Tumble (the littlest, boy),
Rosehip (the wise old keeper, girl). Each needs its own fur colour, head wrap or hat, leaf skirt colour and trinket,
little fangs and claws, big dark eyes and pointy ears like the picture. Empty, free-hanging hands in the picture:
bows and quivers are added after as separate props.
